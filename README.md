# Vector — Flight Decisions v0.1

Decision-first PWA prototype for nonrev tracking.

Core philosophy: Action first. Reason second. Evidence third.

## iPhone use
Host these files with GitHub Pages or any static host, then open the URL in Safari and choose Share → Add to Home Screen.

## Features
- Add tracked flights
- Add observations by paste or screenshot OCR
- Local autosave
- Export/import backup JSON
- Decision-point-first Janus recommendation
- Desired cabin vs minimum acceptable cabin probabilities
- “What would change my mind?” and “Why?” briefing
